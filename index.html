FAQ

Pertanyaan yang sering muncul

Bisakah saya membuka file SketchUp (.skp)?

Format .skp tertutup dan tidak bisa dibaca langsung oleh browser. Ekspor dari SketchUp ke COLLADA (.dae) lalu impor di sini, lengkap dengan teksturnya. Paket Pro dan Studio juga bisa mengunggah .skp ke konverter server.

Apakah perlu instal aplikasi?

Tidak. Rangka 3D berjalan di Chrome, Edge, Firefox, dan Safari versi terbaru. Komputer dengan kartu grafis terintegrasi umumnya cukup untuk rumah satu sampai dua lantai.

Di mana proyek saya disimpan?

Proyek cloud disimpan di server cloud kami dan terhubung ke akun Google Anda. Anda juga bisa menyimpan proyek sebagai file .rk3 di komputer Anda kapan saja (File › Save Project to Computer) dan membukanya lagi tanpa perlu login.

Apa yang terjadi jika kuota Free penuh?

Proyek yang sudah ada tetap aman. Hapus proyek lama, simpan ke file, atau upgrade ke Pro untuk ruang 10 GB.

Bisakah berhenti berlangganan?

Bisa kapan saja. Akun kembali ke Free di akhir periode tagihan, dan proyek Anda tetap bisa dibuka.
